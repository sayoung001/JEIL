# 노트북 — VS Code 에서 셀 단위로

GUI 를 띄우지 않고 **한 단계씩 확인하며** 쓰고 싶을 때 씁니다.
숫자가 왜 그렇게 나왔는지 중간 과정을 볼 수 있습니다.

## 여는 법

1. VS Code 에서 이 프로젝트 폴더를 엽니다.
2. `notebooks/01_시작하기.ipynb` 를 더블클릭합니다.
3. 오른쪽 위 **커널 선택** → `.venv` 를 고릅니다.
   (처음이면 `ipykernel 설치` 를 물어봅니다. **예**를 누르세요.)
4. 첫 셀에 커서를 두고 `Shift+Enter`.

`.venv` 가 아직 없다면 먼저 `Ctrl+Shift+P` → `Tasks: Run Task` → **의존성 설치**.

## 무엇부터 열까

| 노트북 | 언제 |
|---|---|
| **01_시작하기** | 새 PC 에서 처음. 점검 · 경로 맞추기 · 폴더 만들기 |
| **02_월간실적보고서** | 매달 감리 제출 전. 실시대장을 세어 건수 집계 |
| **03_성적서_읽기** | 성적서에서 무엇이 읽히는지 확인. 파서를 손볼 때 |
| **04_서류투입** | 원본 사진·성적서를 넣고 분류 |
| **05_현황점검** | 현황 덤프 · 시험 도래 판정 · 정합성 검사 |

## 안전 장치

파일을 **고치는** 셀은 잠가 뒀습니다.

```python
실행하기 = False       # <- True 로 바꿔야 실제로 돕니다
```

`쓰기` · `넣기` · `실행하기` 가 그렇습니다. 잘못 눌러도 원본이 바뀌지 않습니다.
읽기만 하는 셀(집계·점검·추출)은 그냥 실행하면 됩니다.
